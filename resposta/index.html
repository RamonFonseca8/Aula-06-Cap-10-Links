Introdução ao MVC


O padrão MVC (Model-View-Contrller) é uma arquitetura de software utilizado no desenvolvimento de aplicações para separar a lógica, a interface do usuário e o controle dos dados.


Componentes do MVC


  • Model(Modelo)-Representa os dados e a lógica de nogócios da aplicação.
  • View(Visão)-Responsável pela interface com o usuário e exibição dos dados.
  • Controller(Controlador)-Intermedia a comunicação entre Model e View.
